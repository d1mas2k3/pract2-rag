# Управление служебными доступами

## Временные права
Временные административные права выдаются на 8 часов по заявке IAM-31. По истечении срока доступ снимается автоматически.

## Сервисные учётные записи
Заявку на сервисную учётную запись согласовывает владелец системы. Секреты передаются через корпоративное хранилище.
